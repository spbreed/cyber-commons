▦The idea the whole course hangs off

Read this before the first lesson. A taught session opens with it; alone, read it and move on.

Function A built the platform. This function is the one that asks what can go wrong with it, and it spends its whole first chapter — twenty lessons — doing nothing but naming risks against components you already wrote. That order is the argument: a control chosen before the risk is named is a control chosen because it was easy to buy.

The shape is three chapters and it is deliberate. B1 is the register: every risk CyberTravels carries, one lesson each, ending in the register itself and the control index. B2 closes the two controls that shut the most of them — knowing who is calling, and marking what came in from outside. B3 is the layer that still holds after identity has been defeated: default-deny on the tool call, a sandbox, egress, budgets, and an approval path that survives volume.

The thing to keep saying out loud is that B1 is not the scary chapter and B2–B3 the reassuring one. B1.18's register is a scorecard with a column for the owning control, and most of that column is empty when you first fill it in. The empty cells are the backlog, in the same units as everything else — that is what makes this function usable rather than alarming.

▶Chapter by chapter, lesson by lesson

Each lesson's risk, control, days, measure and skill — and, folded, what that skill prints.

B1 — CyberTravels' Architecture, and Every Risk It Carries

Twenty lessons, each one risk, each attached to a component you built in Function A. The chapter is front-loaded on purpose: B1.0 says what securing an architecture means and B1.1 draws the reference architecture, and everything from B1.2 to B1.17 hangs off that drawing.

B1.18 and B1.19 are not optional. The register turns eighteen separate risks into one scorecard, and the control index adds the controls that are not new — the ordinary ones a programme built only from the agentic rows would miss entirely.

For a room

This is nine lessons longer than any other chapter in the curriculum. Budget for it as two sessions with the register opening the second, not as one long one.

B3.9Turning a control off without turning the system into an experiment1 skill
Risk

Classifiers off, no compensating cap, and tens of thousands of agents launched under that configuration. Each decision was defensible; the combination was never evaluated.

Control

An exemption gate the platform enforces (C6.1), caps that tighten as coverage drops (C6.2), quotas on population and lifetime (C8.2), and an exemption register reviewed at fleet-launch approval (C6.4).

B3.10The agent's escalation path1 skill
Risk

An agent that finds a live breach, reasons about telling someone, and has no tool for it, does nothing. Of roughly 1,200 agents that saw one, none reported it.

Control

A report-to-human tool that is cheap, non-terminal and signposted (C9.1), a mandatory checkpoint on out-of-scope discovery (C9.4), and an abstain affordance scored neutrally (C10.2).
