COURSE GUIDES

Six tracks, one guide each

6 guides149 lessonsSelf-study or taught

These are not six subjects. They are the parts a security organisation is made of — architecture and infrastructure, application security, offensive security, the SOC, and governance — and each guide is the run sheet for one of them: what changes in that work, the chapters in order, every lesson's risk, control and measure, the skill it runs and what that skill prints, plus the pitfalls, a quick check, and the blocks marked For a room for anybody running it as a session.

Start with Function A whatever your job is: it builds the system the other five tracks are about, and it is hard to secure an agent you have never built. Its guide is also the one with a hand-verified output for every lab, because it has sixteen of them.
