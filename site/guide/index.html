Overview

The problem

Breakout time — how long it takes an attacker to get from first access to moving sideways — is now 29 minutes. The fastest on record is 27 seconds. Most security work is still done more slowly than that: architecture reviewed every few months, alerts read one at a time, controls checked once a year.

The solution

Six tracks. The first builds an agentic system, and the other five each take one part of a security organisation — architecture and infrastructure, application security, offensive security, the SOC and governance — and teach how that work changes when agents do it. You also learn how to secure the AI itself.

How you know it worked

Every lesson answers three questions in order: Day 0, why this is worth doing; Day 1, the thing you build; Day 2, the number that tells you next quarter that it still works.
