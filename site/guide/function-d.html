Overview

The problem

Nobody can tell you how your agentic system fails until somebody has tried to break it. Deterministic exploits have signatures; an agentic failure is a reasoning loop, code generated at run time and tool calls at machine speed, and none of that shows up in a scanner. Doing nothing here means your first real evidence arrives as an incident.

The solution

Work one lifecycle end to end rather than collecting techniques: the ingestion and supply-chain surfaces an attacker reaches first, elicitation that scales, then the pivot — turn what you found into gateway telemetry, a deployable detection, a triage playbook, containment and a forensic replay, and hand it over as policy.

How you know it worked

A transcript is not a finding. Every technique reports a reproduction rate across attempts with its denominator, every detection reports the queue volume it would add, and every finding leaves with an evaluation case that fails on the unfixed build — so the fix is verifiable and cannot regress unnoticed.

▦The idea the whole course hangs off

Read this before the first lesson. A taught session opens with it; alone, read it and move on.

One red-team lifecycle, twelve lessons, start to finish. Not a catalogue of attacks — a single engagement run end to end, from the ingestion path through to the governance record it leaves behind.

The thing that makes this function different from the usual red-team material is D1.0's subject: non-deterministic threat simulation. An attack that works once against a model is not a finding. Most of this function is about the arithmetic of that — rates with intervals, seed spread beside the rate, floors, and what a swarm does to a triage queue that was built for individual alerts.

The second half turns around. D1.4 onwards is the defender's side of the same lifecycle: telemetry, high-concurrency detection, triaging the swarm, deception and threshold failures, machine-speed containment, forensic replay, and the compliance record. Red and blue are the same twelve lessons read from two ends, which is why the function is one chapter.

✓Capstone

  1. Pick one finding from your run and state its rate, its denominator and its seed spread. If any of the three is missing, it is not yet a finding.
  2. Say which of your detections would survive the swarm in D1.5. Most per-run detections do not, and that is the point of D1.6.
  3. Produce the replay. D1.10's run should be reproducible by somebody who was not there. If it is not, the forensic half of the lifecycle is missing.
For a room

Have one pair attempt to reproduce another pair's finding from their record alone. Whether they can is the honest score for the whole session.

✎Quick check

Cover the answer column, or use any three with a room.
