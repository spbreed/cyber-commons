Overview

The problem

Your SOC was tuned for people. One hour of an agent is roughly 1,400 tool calls across 260 resources; one hour of a person is twelve actions. Every threshold, baseline and playbook you own was set against the second number, and four of the nine things an agent does in an ordinary day are seen by none of the four sensor classes you already bought.

The solution

Build it in five phases, on open source you can run: discover with the sensors you have plus agent telemetry that no product emits, detect against a lake tiered by the queries you actually run with rules mapped to MITRE, understand with bounded investigation and correlation across the fleet, respond with tiers derived from reversibility, and recover with replay, root cause and a policy diff.

How you know it worked

Five intervals, one per phase, and all five are numbers: time to discover, to detect, to understand, to contain, and to recover to target. CyberTravels' detection interval is 194 minutes against a 15-minute target and its manual containment finishes in 34 minutes against a 29-minute breakout. Every lesson says which interval it shortens, or which one it spends on purpose.

▦The idea the whole course hangs off

Read this before the first lesson. A taught session opens with it; alone, read it and move on.

Five chapters that are five intervals of one clock. E1.0 sets it up and every lesson in the function is anchored back to it: discover, detect, understand, respond, recover. Each chapter shortens one interval, and the anchor line on every page says which.

The agent-shaped problem runs through all five. A sensor estate built for people sees an agent as either a volume anomaly or nothing at all; an alert queue built for one analyst reading one alert does not survive a fleet; a containment plan built around disabling an account does not stop a workload holding an issued token. Each chapter is the same correction applied to a different interval.

The one sentence to keep returning to is that a detection without a named subject is a volume rule. E2.2's subject is the agent, E2.3's is the agent platform, and E3.4 is the lesson on the three instincts that misfire when the actor turns out to be an agent rather than a person.

E2.1The detection data lake — where agent telemetry lands1 skill
Risk

Everything is indexed hot because nobody priced it, so retention is cut across the board and the traces go first.

Control

A tiering decision per source, driven by the queries the SOC actually runs, with the cost of each tier stated.

Day 0 — why it mattersDay 1 — what you do
Everything is indexed hot because nobody priced it, so retention is cut across the board and the agent traces go first.Tier each source by the fastest query that reads it, and price the result against indexing everything.

E2.6Honeypots, canaries and deception — the detector with no threshold1 skill
