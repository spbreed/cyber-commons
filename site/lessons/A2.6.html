Risk

Secrets end up in agent code because there was nowhere else to put them.

Control

Gateway-side credential exchange: virtual keys, JWKS validation, identity mapping.

The lab

Move every credential out of the agent and into the gateway.

cd labs/a2-delegation
docker compose up -d agentgateway kmcp
grep -r 'API_KEY\|token' agent/ || echo 'no secrets in agent code'
curl -s localhost:8080/mcp/tools -H "Authorization: Bearer $(cat svid.jwt)" | jq '.tools[].name'
ExpectThe agent holds only its SVID; the gateway exchanges it for the downstream credential.
