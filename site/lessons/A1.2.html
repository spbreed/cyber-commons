Risk

Controls assumed to live 'in the agent' are advisory, not enforced.

Control

Identity fabric → agentic gateway → policy decision point → sandboxed runtime → audited action plane.

The lab

Stand up the whole reference control plane locally.

cd labs/a1-control-plane
kind create cluster --config kind.yaml
kubectl apply -k spire/     # identity fabric
kubectl apply -k gateway/   # agentgateway
kubectl apply -k opa/       # policy decision point
./verify.sh                 # asserts each layer actually enforces
Expectverify.sh fails loudly if any layer is advisory rather than enforcing.
