Risk

Legacy services see only the human's token and grant everything.

Control

Token translation plus action-class blocking at the boundary.

The lab

Teach a legacy service to refuse agent writes it cannot understand.

cd labs/a2-delegation
python3 action_class.py --allow read --deny protected-branch-merge --by-token-type agent
./try.sh --as agent --action read      # 200
./try.sh --as agent --action merge     # 403 at the gateway, not the app
ExpectThe legacy app is unchanged; the boundary does the work.
