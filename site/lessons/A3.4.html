Risk

Connector chaining as privilege escalation; unpinned servers.

Control

Server scanning, version pinning with hash verification, self-hosting.

The lab

Escalate through connector chaining, then pin and scan to stop it.

cd labs/a3-sandbox/mcp
python3 chain.py --from filesystem --to http   # exfil via two 'safe' connectors
kmcp scan ./servers/ && kmcp pin --hash-verify
python3 chain.py --from filesystem --to http   # blocked
ExpectNeither connector is dangerous alone. The chain is the vulnerability.
