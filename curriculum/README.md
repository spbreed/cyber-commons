## Seniority overlay

Every track runs at three depths. The topics don't change; the accountability does.

| Depth | Typical grade | What you do | Assessment |
|---|---|---|---|
| **Practitioner** | Analyst, Engineer I–II | Operate loops others built. Recognise failure modes. Escalate correctly. Produce evidence. | Run the lab, explain what the trace shows |
| **Engineer** | Senior Engineer, Lead | Build the harness, the control, the detection, the eval. Own a component end to end. | Ship the deliverable to production |
| **Principal** | Principal, Architect, Head of | Decide what is structurally possible. Set promotion criteria. Hold stop authority. | Defend the design in an adversarial review |
