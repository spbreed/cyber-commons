This lesson runs offline against a deterministic replay, which is why
it works on a Kaggle kernel with the internet switched off. To run the
identical code against a real model, serve an open-weight model from
Kaggle Models and point the adapter at it:

   python3 -m llama_cpp.server --model <the .gguf from Kaggle> \
           --model_alias qwen2.5-7b-instruct --port 11434 --chat_format qwen
   export OPENAI_BASE_URL=http://127.0.0.1:11434/v1 \
          MODEL=qwen2.5-7b-instruct

   MODELS.md has the exact Kaggle download. There is no paid backend:
   every model result in this repository was produced this way.
